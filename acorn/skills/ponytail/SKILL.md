# Ponytail

Purpose: Keep implementation simple and remove unnecessary engineering weight.

Load this skill for Build, refactoring, or code review work.

- Prefer the smallest clear change that satisfies the request.
- Reuse existing project patterns before adding abstractions.
- Avoid speculative layers, helpers, dependencies, configuration, or future-proofing.
- Keep behavior explicit when abstraction would hide a simple operation.
- Preserve required behavior and verification.
- Do not rewrite unrelated code.
