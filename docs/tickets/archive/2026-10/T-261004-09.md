# Show Git state before and after actions

## Goal

Make Git operations easier to understand by showing how repository state changed after an action.

## Do

- Capture lightweight state before supported Git Next actions.
- Compare it with the refreshed state afterward.
- Show meaningful deltas such as ahead 3 → 0, branch changed, upstream changed, or dirty → clean.

## Keep

- Keep snapshots lightweight and temporary.
- Do not persist sensitive file contents.
- Show only meaningful state changes instead of noisy raw Git output.

## Done

- Supported actions can present a concise before/after state summary.
- No-change results are handled cleanly.
- Focused tests and build pass.
