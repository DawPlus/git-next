# Auto-refresh graph and sidebar on external Git changes

## Goal

Keep graph and sidebar current when commits, checkouts, or other Git mutations happen outside Git Next.

## Do

- Prefer the built-in `vscode.git` extension API (`API.getRepositories`, repository state change events) over polling or blind full reloads.
- Subscribe to repository state changes for HEAD, refs, index, and working-tree updates.
- Debounce refreshes so rapid external changes do not thrash the UI.
- Update sidebar status and open graph views without requiring a manual refresh for common external commit/branch switches.
- Keep a manual refresh path as a fallback; file watchers only if the Git API is unavailable.

## Keep

- Do not fight in-progress Git Next operations; avoid mid-action UI resets that discard confirmations.
- Bound watcher scope to the active repository roots.
- Prefer pairing with T-261005-10 so auto-refresh does not full-replace webview HTML.

## Done

- External commit or branch switch updates sidebar/graph without manual refresh in the common case.
- Rapid changes are debounced; UI remains usable.
- Focused tests and build pass.
