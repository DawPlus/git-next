# Link glossary terms to live repository state

## Goal

Connect glossary definitions to the user’s actual HEAD, ahead/behind, and related live state.

## Do

- When opening a glossary term, show a live example from the current repository when available.
- Map terms such as Push, Pull, upstream, and diverged to current counts or refs.
- Keep a fallback generic explanation when live state does not apply.

## Keep

- Read-only educational feature.
- Reuse glossary and git-state data; avoid duplicate definitions.
- Do not overload the glossary with action buttons that belong in Doctor or sync flows.

## Done

- Glossary entries can show live repo-mapped examples.
- Missing or irrelevant live state falls back cleanly.
- Focused tests and build pass.

## Result

Glossary cards now show live HEAD, branch, upstream, Push/Pull counts, and divergence examples when repository state applies; generic examples remain the fallback. Verified 20 focused glossary/workspace/shell tests with T-25, build, and diff check.
