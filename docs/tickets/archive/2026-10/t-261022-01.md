# Git 학습 흐름 개선

Goal: 승인된 다섯 개선을 순차 반영한다.
Do: 변경 선택 안내 → 작업별 충돌 설명 → Commit 결과 설명 → 실습 자기확인/상태검사 구분 → PR 대상 선택.
Keep: 기존 안전 검사, 선택 Stage 내용, 사용자 변경. 커밋/배포 없음.
Done: 관련 회귀 테스트, 전체 테스트, typecheck/build, AI QA 통과.
Role: worker (현 세션 직접 실행), coordinator/qa 순차 검증.

## 실행 기준
- 미Stage 상태의 다음 추천은 변경 목록 열기. 전체 Stage 버튼 유지.
- 충돌 설명은 실제 ref/commit 및 작업 종류 사용. Rebase ours/theirs 의미 구분.
- Commit 결과는 실제 커밋 파일 수, 남은 변경 수, 로컬 생성임을 설명.
- 실습의 자기확인과 자동 검증 완료를 구분하고 자동 검사 우회 금지.
- PR 대상 선택을 비교/초안/URL에 동일 적용. 취소는 작업 중단.

## 검증 보정
전체 검사에서 기존 Stage 추천/실습 완료 문구 기대값 2개 불일치. 승인된 동작으로 테스트 갱신.
