# Support multi-root workspaces and multiple repositories

## Goal

Let Git Next operate on the repository the user is working in when several workspace folders or repos are open.

## Do

- Replace `getCwd()` reliance on `workspaceFolders[0]` only.
- Resolve the active repository from the active editor, selected resource, or an explicit repo picker when ambiguous.
- Scope sidebar, graph, sync, and branch actions to that selected repository.
- Persist or clearly show which repository is active in multi-folder workspaces.

## Keep

- Single-folder workspaces keep current behavior.
- Do not require a monorepo-specific layout beyond multiple Git roots.
- Avoid scanning unrelated folders beyond workspace roots.

## Done

- Actions and status reflect the selected repo, not always folder[0].
- Focused tests and build pass.
