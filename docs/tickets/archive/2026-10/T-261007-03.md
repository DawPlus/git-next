# T-261007-03 — Reuse Git state within a single action flow

## Goal
Reduce redundant local Git subprocesses during Push/Pull and other stateful actions by reusing already-read repository state within the same action flow.

## Do
- Identify repeated reads of branch, upstream, tracking, working-tree, and related local state inside a single Push/Pull request.
- Introduce an action-scoped state/context object that can be passed through preflight, impact preview, and execution preparation.
- Reuse state that is demonstrably still valid before the Git mutation begins instead of spawning duplicate Git commands; do not reuse a value across a step that may itself fetch, checkout, merge, rebase, stash, commit, or otherwise change repository state.
- Keep state reuse limited to the current action/request scope; do not introduce a long-lived global repository cache in this ticket.
- After a mutating Git operation succeeds, read fresh state again before producing the final delta/result.
- Avoid redundant final refreshes only when the exact fresh post-mutation state needed by the existing UI is already available; otherwise keep the existing final refresh.
- Keep APIs explicit about whether they require cached pre-action state or fresh post-action state.

## Keep
- Preserve all existing Safe Guard decisions and confirmation behavior.
- Do not reuse pre-mutation state after a mutation.
- Do not weaken remote freshness checks required by T-261007-01.
- Preserve accurate before/after state-delta messages.
- Keep failure paths conservative: if reused state is unavailable or invalid, fall back to a fresh read.

## Done
- A normal Push/Pull flow performs fewer duplicate local Git state reads before mutation.
- Preflight and impact preview can share the same action-scoped state where valid.
- Post-mutation state is still freshly read.
- State-delta output remains correct.
- No stale state is reused across separate user actions.
- Focused tests verify reuse before mutation and fresh reads after mutation.
- Full tests, typecheck, and build pass.
