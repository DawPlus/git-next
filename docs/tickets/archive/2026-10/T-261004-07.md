# Add branch cleanup assistant

## Goal

Help users identify local branches that are safe or useful candidates for cleanup.

## Do

- Identify merged local branches, branches whose remote tracking ref is gone, and stale local branches when determinable.
- Explain why each branch is suggested.
- Require explicit confirmation before deletion.

## Keep

- Never delete the current branch.
- Treat uncertain merge/remote state conservatively.
- Keep cleanup recommendations separate from automatic deletion.

## Done

- Users can review cleanup candidates with reasons.
- Unsafe or uncertain branches are not presented as safe deletions.
- Focused tests and build pass.

worker
