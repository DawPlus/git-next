# Add nonce-based CSP to webview panels

## Goal

Meet VS Code webview security guidance for every panel that runs with `enableScripts: true`.

## Do

- Add a `<meta http-equiv="Content-Security-Policy">` (or equivalent CSP header via `webview.cspSource`) to each script-enabled webview HTML.
- Use a per-render nonce for inline scripts and restrict `script-src` / `style-src` to that nonce plus `webview.cspSource` as needed.
- Cover graph, sidebar/host, guides, and any other panels that enable scripts.

## Keep

- Do not disable scripts required for current UI behavior.
- Preserve existing markup/CSS appearance.

## Done

- Every `enableScripts: true` webview ships a CSP with nonce-based script allowlisting.
- Panels still render and handle messages after CSP is applied.
- Focused tests and build pass where HTML builders are covered.
