# Save AI diagnosis history

## Goal

Keep useful AI Git diagnoses so users can revisit what happened, what the AI recommended, and how the situation was resolved.

## Do

- Store timestamp, repository identity, situation key, summary, risk, recommendation, selected guide/preset, provider label, and resulting action/outcome when known.
- Add a history view reachable from the AI diagnosis experience.
