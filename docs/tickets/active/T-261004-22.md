# Require meaningful stash messages with preview

## Goal

Reduce anonymous WIP stashes by prompting for a useful message and showing what will be saved.

## Do

- Prompt for a stash message before save when the user did not supply one.
- Preview included files or change summary before creating the stash.
- Keep a way to accept a default message deliberately.

## Keep

- Do not block power users with unavoidable friction; allow an explicit default.
- Preview remains read-only until confirm.
- Preserve existing stash apply/pop flows.

## Done

- New stashes can carry an intentional message and pre-save preview.
- Users still can stash quickly with an explicit default choice.
- Focused tests and build pass.
