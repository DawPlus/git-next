# Show merge base in graph compare

## Goal

Make the common ancestor of two branches visible so users can see where histories split.

## Do

- Resolve the merge base for two selected refs.
- Highlight that commit in graph/compare context.
- Explain in plain language that this is the shared point before the branches diverged.

## Keep

- Read-only feature.
- Do not confuse merge base with a merge commit.
- Reuse existing branch compare UI where practical.

## Done

- Branch comparison can identify and surface the common ancestor.
- The graph clearly shows where the compared histories split.
- Focused tests and build pass.
