# Show whether a commit is contained in the current branch

## Goal

Tell users if a selected commit is already reachable from the current branch and how it relates.

## Do

- For a selected commit, report contained / not contained relative to HEAD or a chosen ref.
- When useful, show a short path hint for cherry-pick or rebase candidacy.
- Highlight the commit in the graph context.

## Keep

- Read-only feature.
- Do not auto cherry-pick or rebase.
- Keep explanation plain; avoid assuming advanced ancestry vocabulary.

## Done

- Users can check commit containment for the current branch or selected ref.
- Graph highlight matches the containment result.
- Focused tests and build pass.

worker
