# Add Git Doctor

## Goal

Diagnose the repository's current Git health in one place and suggest the safest next action.

## Do

- Detect detached HEAD, no upstream, dirty worktree, ahead/behind/diverged, and in-progress Git operations.
- Surface remote-history rewrite suspicion when existing Safe Guard checks can detect it.
- Explain each finding as state, risk, and recommended next action.

## Keep

- Reuse existing Safe Guard/state logic instead of duplicating Git checks.
- Diagnostic only by default; do not mutate repository state automatically.

## Done

- One Git Doctor view/action summarizes current repository health.
- Findings link users toward the relevant existing Git Next action or guide.
- Focused tests and build pass.

worker
