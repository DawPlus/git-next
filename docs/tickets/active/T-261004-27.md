# Add lightweight commit message quality hints

## Goal

Improve commit message drafts with simple quality hints without becoming a style enforcer.

## Do

- Hint on missing what/why signal, overly long subject lines, and empty bodies when a draft exists.
- Keep suggestions advisory beside the existing commit message draft helper.
- Allow users to ignore hints and continue.

## Keep

- No hard block on commit messages.
- Do not invent project-specific conventional-commit policy unless configured later.
- Stay out of VS Code SCM commit ownership; hints are for Git Next draft help only.

## Done

- Commit message drafts can show concise quality hints.
- Users can dismiss or ignore hints freely.
- Focused tests and build pass.
