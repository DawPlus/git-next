# Add recovery points before risky actions

## Goal

Create a lightweight recovery point before history-changing Git operations so users can recover from mistakes.

## Do

- Create a recoverable local ref/branch before selected risky actions such as Reset or Rebase.
- Show what was captured and how to return to it.
- Provide a clear recovery action from Git Next.

## Keep

- Do not create recovery refs for harmless read-only operations.
- Keep naming predictable and local-only unless the user explicitly pushes it.
- Reuse existing confirmation and recovery flows where possible.

## Done

- Supported risky actions can create a recovery point before mutation.
- Users can identify and restore from the created point.
- Focused tests and build pass.
