# Explain why a remote-tracking branch is gone

## Goal

Help users understand and act when a remote-tracking branch is gone.

## Do

- Detect gone upstream / missing remote-tracking refs.
- Explain likely causes: remote branch deleted, prune needed, or fetch stale.
- Offer safe next actions such as fetch, prune, or local branch cleanup review.

## Keep

- Do not auto-delete local branches.
- Treat uncertain remote state conservatively.
- Link to branch cleanup assistant when deletion is the right next step.

## Done

- Gone-remote cases show cause hypotheses and safe next actions.
- Destructive options require explicit confirmation.
- Focused tests and build pass.
