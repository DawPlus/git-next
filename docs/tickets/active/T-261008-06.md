# T-261008-06 — Strengthen TypeScript strictness incrementally

## Goal
Make `npm run typecheck` catch materially more defects by moving the codebase toward strict TypeScript without forcing a risky all-at-once migration.

## Do
- Audit current `strict`, `noImplicitAny`, and related compiler settings.
- Enable stricter checks in a staged way, starting with core Git state/safety modules that already have strong types.
- Add missing parameter/return types at module boundaries used by extension host, handlers, and repository state.
- Use narrow local exceptions only when necessary and document them.
- Create a follow-up map for modules that cannot yet satisfy full strict mode.

## Keep
- No blanket `any` or new `@ts-nocheck` to make the compiler quiet.
- Preserve runtime behavior.
- Do not combine this with large architectural rewrites.

## Done
- Typecheck catches implicit/unsafe types in at least one meaningful production slice.
- Strictness increases measurably without broad suppression.
- Remaining non-strict areas are documented.
- Full tests, typecheck, and build pass.

## Role
worker

- `tsconfig.json`
- `src/extension-core.ts`
