# Add detached HEAD escape guide

## Goal

Help users leave detached HEAD safely with clear keep-or-discard choices.

## Do

- Detect detached HEAD and explain the current commit position in plain language.
- Offer create-branch-here versus return-to-branch paths.
- Warn when leaving would make the current commit harder to find.

## Keep

- Do not discard commits without confirmation.
- Prefer creating a named local branch when the user wants to keep work.
- Reuse existing branch creation and checkout confirmations.

## Done

- Detached HEAD shows an escape guide with keep/discard outcomes.
- Users can return to a branch or preserve the commit with a name.
- Focused tests and build pass.
