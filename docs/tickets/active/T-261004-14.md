# Add undo recommendation engine

## Goal

After a Git Next action, recommend the safest single undo/recovery path for that action type.

## Do

- Map recent supported actions to preferred recovery options such as recovery ref, revert, or reflog-based restore.
- Rank options by safety and show why the top recommendation is preferred.
- Deep-link into the existing recovery flow when a recovery point exists.

## Keep

- Recommend one primary action; keep advanced options secondary.
- Do not run destructive undo automatically.
- Reuse recovery points and timeline data where available.

## Done

- Supported actions can show a clear safest undo recommendation.
- Users can start recovery without guessing Git commands.
- Focused tests and build pass.
