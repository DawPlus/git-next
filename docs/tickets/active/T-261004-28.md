# Add failed-action timeline with retry checks

## Goal

Collect recent Git Next failures/blocks and help users retry only after the blocking condition is addressed.

## Do

- Record recent failed or Safe Guard-blocked actions in the existing timeline style.
- For each entry show why it failed/blocked and what to check before retry.
- Offer a retry entry point that re-runs prechecks first.

## Keep

- Do not auto-retry destructive actions.
- Keep stored details free of sensitive file contents.
- Reuse before/after and Safe Guard explanations where possible.

## Done

- Users can review recent failures/blocks and retry with prechecks.
- Retry remains confirmation-based for mutating actions.
- Focused tests and build pass.
