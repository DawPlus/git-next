# Add first-push wizard for branches without upstream

## Goal

Guide users through the first Push when the current branch has no upstream.

## Do

- Detect missing upstream before Push.
- Offer remote selection, branch name confirmation, and `-u` setup in one flow.
- Explain what tracking will mean after success, and next steps on failure.

## Keep

- Do not invent remotes; only use configured remotes.
- Keep the wizard optional when the user already knows the command path.
- Reuse existing Push confirmation and Safe Guard checks.

## Done

- No-upstream Push can complete through a guided confirmation flow.
- Failure paths point to a concrete next action.
- Focused tests and build pass.

worker
