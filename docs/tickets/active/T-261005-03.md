# Merge selected branch into current branch

## Goal

Complete the create → work → merge branch flow from the Branches UI.

## Do

- Add a Branches action to merge the selected branch into the current branch.
- Show a preview (incoming commits, merge base when available, dirty-tree/conflict risk) and require confirmation.
- On conflicts, route to the existing in-progress merge continue/abort path.
- Block or warn clearly when the selected branch is current, missing, or merge is already in progress.

## Keep

- Do not auto-delete the source branch after merge.
- Reuse Safe Guard and conflict-helper patterns.
- Share preview conventions with diverged Merge/Rebase where practical.

## Done

- Branches UI can merge another branch into the current branch with preview and confirm.
- Conflict and dirty-tree cases are guided without leaving users stuck at explanation only.
- Focused tests and build pass.
