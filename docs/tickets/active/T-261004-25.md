# Add situational scenario card library

## Goal

Teach common Git trouble states with reusable scenario cards users can compare to their repo.

## Do

- Cover key situations such as diverged, rejected non-fast-forward, dirty pull, and gone upstream.
- For each card show state, risk, and safest next action pattern.
- Optionally relate the selected card to the current repository state when detection exists.

## Keep

- Educational first; do not mutate the repo from a card alone.
- Reuse Doctor/Safe Guard findings for “matches your repo” hints.
- Keep copy in plain Korean-friendly product language already used by Git Next.

## Done

- Users can browse scenario cards and map them to next actions.
- Cards that match current state can be highlighted when detection is available.
- Focused tests and build pass.
