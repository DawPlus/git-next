# Jump from file history to graph commits

## Goal

Let users pick a file and jump to its related commits highlighted on the graph.

## Do

- Accept a file path and resolve recent commits that touched it.
- Highlight those commits in the graph and focus the relevant range when practical.
- Show a short list of matching commits for direct selection.

## Keep

- Read-only navigation feature.
- Bound history depth to avoid heavy loads by default.
- Reuse existing graph focus/highlight mechanisms where possible.

## Done

- Users can move from a file to highlighted graph commits.
- Empty and large-history cases degrade gracefully.
- Focused tests and build pass.
