# Preview stash conflicts

## Goal

Warn users when applying a Stash is likely to overlap with current working changes.

## Do

- Inspect files touched by the selected Stash.
- Compare them with current working-tree changes before Apply or Pop.
- Highlight overlapping files and explain Apply versus Pop behavior.

## Keep

- Preview must be read-only.
- Do not claim a conflict is certain when only file-level overlap is known.
- Preserve existing Stash confirmation flow.

## Done

- Apply/Pop can show overlap risk before execution.
- Users can see which files need attention.
- Focused tests and build pass.
