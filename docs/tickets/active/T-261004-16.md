# Add in-progress Git operation dashboard

## Goal

Show a stuck merge, rebase, or cherry-pick as one dashboard with status and next actions.

## Do

- Detect in-progress merge/rebase/cherry-pick and related conflict state.
- List conflicted files and explain continue versus abort outcomes.
- Preview what continue/abort will change before confirmation.

## Keep

- Diagnostic and guided confirmation only; no surprise continue/abort.
- Reuse conflict explanation and Safe Guard state.
- Keep VS Code merge editor ownership for file-level editing.

## Done

- In-progress operations surface in one place with clear next steps.
- Continue/abort confirmations explain resulting repository state.
- Focused tests and build pass.
