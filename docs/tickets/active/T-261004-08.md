# Strengthen push and pull impact preview

## Goal

Show exactly what Push or Pull is about to affect before the user confirms it.

## Do

- Summarize outgoing/incoming commit counts and changed file counts.
- Distinguish changed/added/deleted files where available.
- Highlight the affected commits in the graph.
- Surface local/remote overlap warnings when existing Safe Guard data provides them.

## Keep

- Preview remains read-only.
- Reuse existing impact preview and Safe Guard data.
- Do not duplicate Source Control file-diff work owned by another ticket/agent.

## Done

- Push/Pull confirmation clearly shows affected commits and files.
- Graph emphasis matches the previewed operation.
- Focused tests and build pass.

worker
