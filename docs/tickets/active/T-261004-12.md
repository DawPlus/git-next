# Strengthen PR readiness checklist

## Goal

Give users one checklist for whether the current branch is ready to open a PR.

## Do

- Summarize ahead/behind/diverged, dirty worktree, untracked files, and upstream state.
- Surface existing PR handoff entry points for GitHub/GitLab.
- Offer a lightweight title/body draft hook when useful.

## Keep

- Do not replace host PR UIs; prepare and hand off only.
- Reuse existing sync and Safe Guard state.
- Avoid CI API scope unless already available locally.

## Done

- Users can review PR readiness and jump to host handoff.
- Blocking issues are listed with next actions.
- Focused tests and build pass.
